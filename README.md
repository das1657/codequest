# codequest
A bunch of [Lockheed Martin CodeQuest](https://lmcodequestacademy.com/) problems I worked on throughout high school in class, at home, or during the actual competitions, all written in Java.

Not every single file will pass however, as some of the programs in this repository are unfinished, or error, and was left here as I moved onto a different problem. I couldn't be bothered to go back and check every single one to see if they passed or not before uploading.
